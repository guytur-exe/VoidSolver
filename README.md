# VoidSolver
**disclaimer:**
this is a **fan** project and **not** an official reposetory by the creators of "Void Stranger", please check out the game on steam by "System Erasure" before reading this reposetory.

**Summary:**
this app is a solver for general puzzles of the games: "Void Stranger"
it uses a BFS search on a "possabilities graph" that is generated mid search of all possible states the level can be in.
this is of course a brute force way of solving it but theoretically will always work given enough time.

**please play this game:**
this app was made just for fun, but I recommend always trying to solve the game alone first because it's fun.
